# 📸 Фотографии Лекции № 01 — «Анатомия шиноби»

В этой папке хранятся фотографии и изображения, используемые внутри страницы лекции `lekciya-01.html`.

## Как добавлять фотографии

1. Положите файлы изображений в эту папку (`.jpg`, `.png`, `.webp`)
2. Используйте осмысленные имена в snake_case, например:
   - `anatomy-skeleton.jpg`
   - `chakra-system.jpg`
   - `tenketsu-points.jpg`
3. Вставьте изображение в страницу лекции:

```html
<img src="lecture1/anatomy-skeleton.jpg" alt="Скелет шиноби">
```

## Важно

- **Иконка карточки лекции** (круглый слот 120x120 на `lekcii.html`) хранится отдельно в `images/lecture-anatomy.jpg`
- **Фотографии внутри лекции** хранятся здесь, в `lecture1/`
