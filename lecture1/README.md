# 📸 Фотографии Лекции № 01 — «Анатомия шиноби»

В этой папке хранятся фотографии и изображения, используемые внутри страницы лекции `lekciya-01.html`.

## Текущие файлы

- `mindbody.svg` — «Разум и тело шиноби» (раздел VIII. Мозг и нервная система)
- `chakraflows.jpg` — «Потоки циркуляции чакры» (раздел X. Система циркуляции чакры)

## Как добавлять фотографии

1. Положите файлы изображений в эту папку (`.jpg`, `.png`, `.webp`, `.svg`)
2. Используйте осмысленные имена в snake_case, например:
   - `anatomy-skeleton.jpg`
   - `chakra-system.jpg`
   - `tenketsu-points.svg`
3. Вставьте превью в страницу лекции:

```html
<div class="lecture-doc__gallery">
    <div class="lecture-doc__photo" data-full="lecture1/nazvanie-foto.jpg">
        <img src="lecture1/nazvanie-foto.jpg" alt="Описание">
    </div>
</div>
```

## Важно

- **Иконка карточки лекции** (круглый слот 120x120 на `lekcii.html`) хранится отдельно в `images/lecture-anatomy.jpg`
- **Фотографии внутри лекции** хранятся здесь, в `lecture1/`
- ⚠️ **Расширение файла должно соответствовать содержимому.** Если файл начинается с `<svg` — это SVG, и расширение должно быть `.svg` (не `.png`). Браузер не отобразит изображение при несовпадении расширения и формата.
