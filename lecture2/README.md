# 📸 Фотографии Лекции № 02

В этой папке хранятся фотографии и изображения, используемые внутри страницы будущей лекции № 02.

## Как добавлять фотографии

1. Положите файлы изображений в эту папку (`.jpg`, `.png`, `.webp`)
2. Используйте осмысленные имена в snake_case
3. Вставьте изображение в страницу лекции:

```html
<img src="lecture2/nazvanie-foto.jpg" alt="Описание">
```

## Важно

- **Иконка карточки лекции** (круглый слот 120x120 на `lekcii.html`) хранится отдельно в `images/`
- **Фотографии внутри лекции** хранятся здесь, в `lecture2/`
